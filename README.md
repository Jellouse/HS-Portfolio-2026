# Humansize

Portfolio site for Johann Schnettker.

Astro, static output, for Vercel. Content is Markdown-free YAML in the repo. Keystatic edits those files locally and you commit the result.

## Scripts

- `npm run dev` starts the site and the CMS at `/keystatic`
- `npm run build` writes `dist/`
- `npm run preview` serves the build

Node 22.

## Vercel

- Framework: Astro
- Build command: `npm run build`
- Output: `dist`
- Set `SITE_URL` to the production origin when the domain is final. Example: `https://humansize.studio`
